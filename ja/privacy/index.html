1. 取得する情報

当社のゲームでは会員登録は不要です。本サービスの提供に必要な最小限の情報のみを取り扱います。

2. 利用目的

  • プレイヤーアカウントの識別、ゲームデータの保存・復元（クラウドセーブ、機種変更時の引き継ぎ）
  • ゲームの提供、アプリ内購入アイテムの付与
  • 不具合の分析、サービスの安定化および品質向上
  • 広告の表示（広告を含むゲームの場合）
  • お問い合わせへの対応、重要なお知らせの送付

3. Google ユーザーデータの取り扱い

当社のゲームは Google ログイン（Google Sign-In / Google Play ゲームサービス）を利用しています。ログイン時の取り扱いは以下のとおりです。

  • アクセスする情報：基本プロフィール（アカウントID、名前、メールアドレス、プロフィール画像）のみです。Gmail、Google ドライブのファイル、連絡先、カレンダーなど、その他の Google アカウントデータにはアクセスしません。
  • 利用目的：プレイヤーアカウントの識別と、ゲームの進行データの保存・復元のためだけに利用します。
  • 共有：Google ユーザーデータを販売することはなく、法令に基づく場合を除き第三者に提供しません。広告、信用評価など、上記の目的と関係のない用途に利用・転送することはありません。
  • 保存と削除：ゲームデータとの紐付けのために保存し、ご依頼があれば速やかに削除します。myaccount.google.com/permissions から、いつでもアプリのアクセス権を取り消すことができます。

当社による Google API から受け取った情報の利用および他のアプリへの転送は、限定的使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

4. 保存期間

個人情報は、利用目的を達成した場合、またはお客様から削除のご依頼があった場合に速やかに削除します。ただし、法令により保存が義務付けられている記録（例：韓国の電子商取引法に基づく購入・決済記録5年、苦情処理記録3年、通信秘密保護法に基づくアクセスログ3か月）は、定められた期間保存します。1年以上ご利用のないゲームデータは、事前にお知らせのうえ削除する場合があります。

6. 削除の方法

不要となった情報は、復元できない方法で速やかに削除します。電子ファイルは技術的な方法で完全に消去し、紙媒体はシュレッダー等で破棄します。

7. お客様の権利

お客様は、ご自身の個人情報の開示、訂正、利用停止、削除などを請求することができます（個人情報保護法その他お住まいの地域の法令に基づく権利を含みます）。ゲーム名とご依頼内容を記載のうえ下記メールアドレスまでご連絡ください。ご本人確認のうえ、遅滞なく（通常10日以内に）対応いたします。

  • アカウント・データの削除：spicerpon@gmail.com 宛に、件名「データ削除依頼」とゲーム名を記載してお送りください。
